# 📦 Digital Time Capsule

A simple Python mini-project that allows users to write messages to their future selves and unlock them on a specific date.

## ✨ Features

- Create personal time capsules.
- Set a future unlock date.
- View all saved capsules.
- Unlock messages when their scheduled date arrives.
- Delete existing capsules.
- Automatically save messages using JSON file handling.

## 🛠️ Technologies Used

- Python
- JSON
- Datetime
- File Handling

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project:

   ```bash
   cd DigitalTimeCapsule
   ```

3. Run the program:

   ```bash
   python main.py
   ```
